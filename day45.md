# 📖 Project Overview

**Decision Report Dashboard** is an interactive decision-making application designed to transform complex choices into a structured, visual, and actionable decision report.

Instead of simply presenting a list of pros and cons, the application evaluates available options based only on the information provided by the user.

It compares options through a decision matrix, identifies weak assumptions, visualizes scores, and produces a decisive final verdict.

The goal is to make decision-making more structured, transparent, and easier to understand.

---

# 🎯 Core Objective

The application helps users answer one important question:

**"Given my actual situation, which option makes the most sense?"**

The system focuses on:

➡ Evidence instead of assumptions
➡ User-provided information instead of invented facts
➡ Clear comparison instead of information overload
➡ Decisive recommendations instead of endless analysis

---

# ✨ Features

## 1. 🧠 Decision Analysis

The application analyzes the user's decision topic and available options.

It focuses only on information provided by the user and avoids fabricating missing facts.

---

## 2. 📊 Decision Matrix

Each option is evaluated through a structured comparison matrix.

The matrix provides:

➡ Option comparison
➡ Individual scores
➡ Visual score bars
➡ Justification for each score
➡ Total score calculation

---

## 3. 📈 Animated Score Visualization

The dashboard includes animated comparison bars.

Features include:

➡ 28px bar height
➡ Rounded progress bars
➡ Gradient-based option colors
➡ Animated loading from 0% to final score
➡ Score displayed directly inside each bar
➡ Staggered animation delays
➡ Highlighted total score row

This makes the decision easier to understand at a glance.

---

## 4. 🧩 Assumption Buster

The **Assumption Buster** identifies weak thinking or unsupported assumptions.

Instead of hiding uncertainty, the application highlights areas where the user's reasoning may need more evidence.

This creates a more honest decision-making experience.

---

## 5. 🏆 Decisive Verdict

The application generates a clear final recommendation.

The Verdict Card includes:

➡ Winning option
➡ Strong visual emphasis
➡ Reasoning behind the decision
➡ "Hard Truth" insight
➡ Clear explanation of the most important trade-off

The system does not avoid making a recommendation when the available evidence supports one.

---

## 6. 📱 Shareable Decision Cards

The dashboard generates three compact shareable cards.

These cards are designed for:

➡ Screenshots
➡ Social media sharing
➡ Personal decision records
➡ Quick comparison
➡ Presenting decisions to others

Each card includes a subtle **Built with Claude AI** watermark.

---

## 7. 🎨 Premium Dashboard UI

The interface includes:

➡ Modern dark theme
➡ Gradient visual elements
➡ Premium dashboard cards
➡ Smooth hover effects
➡ Animated score bars
➡ Responsive layouts
➡ Clear typography
➡ Visual hierarchy
➡ Mobile-friendly design

---

## 8. 📱 Responsive Design

The application adapts to different screen sizes.

On smaller screens:

➡ Cards become full width
➡ Shareable cards stack vertically
➡ Matrix labels adjust automatically
➡ Typography scales down
➡ Padding becomes more compact

# 🚀 How to Run

1. Clone or download this repository.

2. Open the HTML file in a modern browser.

3. Enter your decision topic and relevant information.

4. Complete the decision workflow.

5. Review the comparison matrix.

6. Analyze the Assumption Buster.

7. Review the final Verdict Card.

8. Explore the three shareable decision cards.

9. Take screenshots or save the report for future reference.

No installation or backend setup is required.
