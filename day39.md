# 🚀 Day 39/60 – PDF Splitter & Merger | ABTalks 60 Days Claude AI Challenge


---

## 📖 Project Overview

**PDF Splitter & Merger** is a premium browser-based document management application that enables users to split, merge, preview, and organize PDF files securely without requiring any backend services. All processing is performed locally within the browser, ensuring user privacy and fast performance.

---

## ✨ Features

### 📄 PDF Splitter

* Upload PDF files with automatic page detection
* Preview page thumbnails before processing
* Split PDFs using custom page ranges
* Extract selected pages
* Split after specific pages
* Split every *N* pages
* Create multiple split operations in one session
* Validate page ranges with real-time feedback
* Preview output structure before generating files

### 📑 PDF Merger

* Upload multiple PDF files
* Drag-and-drop file uploads
* Reorder PDFs before merging
* Display total file count and page count
* Merge PDFs directly in the browser
* Download the merged PDF instantly

### 🎨 Additional Features

* Modern responsive UI
* Dark Mode
* Smooth animations & micro-interactions
* Processing indicators
* Keyboard accessibility
* Offline support after initial load
* Privacy-first client-side processing
* Professional user experience

## 🚀 How to Run

1. Clone this repository.
2. Open the HTML file in any modern browser.
3. Upload your PDF files.
4. Split or merge documents as needed.
5. Download the processed PDFs instantly.
