# 🚀 Day 48/60 – Compare & Decide Builder | ABTalks 60-Day Claude AI Challenge



# 📖 Project Overview

**Compare & Decide Builder** is a research-driven decision-making application designed to help users compare real-world options using measurable criteria, verified information, customizable priorities, and transparent research.

Instead of relying only on opinions or assumptions, the application focuses on making the decision-making process more structured and evidence-based.

Users can adjust the importance of different criteria and instantly see how the ranking changes.

---

# 🎯 Core Objective

The main goal of this project is to answer:

**"Which option is the best choice based on the criteria that actually matter to me?"**

The application focuses on:

➡ Evidence-based comparison

➡ Measurable decision criteria

➡ Customizable priorities

➡ Transparent scoring

➡ Real research sources

➡ Explainable rankings

---

# ✨ Features

## 1. 🔍 Research-Based Comparison

The application compares multiple options against clearly defined criteria.

Instead of presenting unsupported claims, each data point is connected to a research source whenever available.

---

## 2. 📊 Multiple Decision Criteria

Users can evaluate options using criteria such as:

➡ Cost

➡ Quality

➡ Risk

➡ Time

➡ Availability

➡ Performance

The criteria can be adapted according to the specific decision.

---

## 3. ⚖️ Customizable Criteria Weights

One of the key features is the ability to change the importance of each criterion.

For example:

➡ Increase Cost → Cost becomes more important

➡ Increase Quality → Quality influences the ranking more

➡ Increase Risk → Safer options receive greater importance

The ranking updates dynamically as the weights change.

---

## 4. 📈 Live Ranking

The application recalculates the comparison when the user changes criteria weights.

This allows users to understand how different priorities can produce different decisions.

---

## 5. 🧾 Sources Panel

Every research-based data point is connected to its source.

The sources panel helps users understand:

➡ Where the information came from

➡ Which source supports a data point

➡ Which information is directly sourced

➡ Whether a value is an estimate or placeholder

---

## 6. 📚 How This Was Researched

A dedicated **"How this was researched"** section explains the research process.

It highlights:

➡ Data sources

➡ Research methodology

➡ Conflicting information

➡ How conflicts were resolved

➡ Important limitations


This makes the final comparison more transparent.

---

## 7. 🚨 Data Transparency

The application clearly identifies information that may be:

➡ Verified data

➡ Estimated values

➡ Synthetic placeholders

This prevents users from confusing assumptions with verified facts.

---

## 8. 📱 Responsive Dashboard

The interface is designed to work across different screen sizes.

The dashboard includes:

➡ Responsive cards

➡ Flexible comparison layouts

➡ Mobile-friendly controls

➡ Clean typography

➡ Accessible interactions

# 📚 What I Learned

Building this project helped me understand:

➡ How to convert real-world decisions into measurable criteria.

➡ How changing criteria weights can significantly change a final ranking.

➡ Why research sources are essential for trustworthy decision systems.

➡ How to make AI-assisted analysis more transparent.

# 💡 Key Takeaway

This project reinforced an important idea:

**A good decision-making system should not only tell you what to choose.**

It should help you understand:

**Where the information came from.**

**How the options were compared.**

**Which criteria influenced the result.**

**And why the recommendation changes when your priorities change.**

# 🚀 How to Run

1. Clone or download this repository.
2. Open the HTML file in a modern browser.
3. Enter the decision you want to analyze.
4. Define the comparable options.
5. Select the decision criteria.
6. Adjust the criteria weights.
7. Observe the ranking update live.
8. Open the Sources panel.
9. Review the "How this was researched" section.
10. Analyze the final comparison.

No installation or backend setup is required.
