# 🚀 Day 49/60 – Personal AI Playbook | ABTalks 60-Day Claude AI Challenge



# 📖 Project Overview

**Personal AI Playbook** is a personalized AI workflow management application designed to help users turn the way they use AI into reusable, structured workflows.

Instead of collecting hundreds of disconnected prompts, the application focuses on creating modular prompt systems that can be customized, combined, saved, and reused for different tasks.

The goal is to help users move from simply **using AI** to building **repeatable AI workflows**.

---

# 🎯 Core Objective

The application helps users create a personal library of AI workflows based on their:

➜ Role and profession
➜ Common AI use cases
➜ Repetitive tasks
➜ Productivity bottlenecks
➜ Preferred AI models
➜ Experience level
➜ Desired outcomes

The system then turns this information into reusable workflow structures instead of generic prompts.

---

# ✨ Features

## 1. 🧠 Personalized AI Workflow Library

The application creates workflows based on the user's actual needs.

Each workflow can include:

➜ Editable templates
➜ Custom variables
➜ Practical examples
➜ Best practices
➜ Reusable instructions
➜ One-click copy

---

## 2. 🧩 Prompt Builder

The Prompt Builder allows users to construct prompts block-by-block.

Available building blocks include:

➜ Role
➜ Objective
➜ Context
➜ Constraints
➜ Reasoning Strategy
➜ Output Format
➜ Tone
➜ Examples
➜ Quality Checks

Each block explains what it does and why it matters.

A live preview shows the complete prompt while it is being assembled.

---

## 3. 🔄 Loop Builder

The Loop Builder converts a normal prompt into an autonomous improvement workflow.

Users can define:

➜ Goal
➜ Evaluation Criteria
➜ Improvement Strategy
➜ Stop Conditions
➜ Safety Rules

This helps transform a one-time AI request into a repeatable improvement loop.

---

## 4. 🧱 Modular Prompt System

Instead of storing hundreds of separate prompts, the application uses reusable building blocks.

These blocks can be combined in different ways to create thousands of possible prompt variations.

This makes the system more flexible and easier to maintain.

---

## 5. ⭐ Workflow Management

Users can manage their personal workflows through:

➜ Create
➜ Edit
➜ Duplicate
➜ Favorite
➜ Search
➜ Filter
➜ Save

Workflows are stored locally using browser Local Storage.

---

## 6. 📤 Import & Export

The application allows users to export their workflow library as a backup file.

This makes it easier to:

➜ Backup workflows
➜ Transfer workflows
➜ Restore saved workflows
➜ Maintain a personal AI library

---

## 7. 💡 Beginner-Friendly Explanations

A major focus of the application is education.

The interface explains:

➜ What each feature does
➜ Why each prompt block matters
➜ How workflows are structured
➜ How normal prompts become loops

The goal is to help users learn **how to build AI systems**, not just copy prompts.

# 🚀 How to Run

➜ Clone or download this repository.

➜ Open the HTML file in a modern browser.

➜ Complete the AI workflow interview.

➜ Explore your personalized workflow library.

➜ Build a prompt using the Prompt Builder.

➜ Convert it into an autonomous loop using the Loop Builder.

➜ Save and favorite your workflows.

➜ Search and filter your workflow library.

➜ Export your workflows as a backup.

No installation or backend setup is required.
