# 🚀 Day 36/60 – Cognitive Pattern Explorer | ABTalks 60 Days Claude AI Challenge

Today I built **Cognitive Pattern Explorer**, a psychology-inspired self-reflection web application that helps users explore different thinking tendencies through interactive activities. The application is designed purely for educational and self-awareness purposes and avoids any clinical assessments or diagnoses.

## 🎯 Project Overview

The application provides a calm, game-like experience where users explore how they approach everyday situations and decision-making through multiple interactive chapters.

## ✨ Features Implemented

* 🧠 Calm Mode and Stress Mode experience
* 🎮 Interactive scenario-based thinking exploration
* 🃏 Drag-and-drop priority organization
* 📅 Thinking timeline arrangement activity
* 📊 Personalized Reflection Journal with percentage breakdown
* 📈 Progress tracking across all chapters
* 📱 Fully responsive design
* ⌨️ Keyboard accessibility support
* ♿ Reduced motion support
* 🎨 Smooth animations and modern UI
* 💾 Works completely offline
* 📄 Single HTML file with inline CSS and JavaScript

## 🛠️ Tech Stack

* HTML5
* CSS3
* Vanilla JavaScript
* Native Drag & Drop API
* Responsive Web Design

## 📚 What I Learned

* Building interactive educational web applications
* Designing engaging self-reflection experiences
* Creating reusable drag-and-drop components
* Improving accessibility and responsive design
* Structuring large single-file JavaScript projects
* Enhancing UI/UX with smooth animations and progress indicators

This project strengthened my frontend development, UI/UX design, prompt engineering, and problem-solving skills while demonstrating how AI can help create meaningful educational applications.
