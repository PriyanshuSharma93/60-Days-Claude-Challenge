# 🚀 Day 37/60 – Task Compass | ABTalks 60 Days Claude AI Challenge

Today I built **Task Compass**, an interactive organizational workflow simulator that helps users understand how work flows through real organizations. Instead of testing job titles, the application teaches ownership, delegation, collaboration, escalation, and workflow management through realistic workplace scenarios.

## 🎯 Project Overview

Task Compass is a game-based learning experience where players solve workplace challenges by assigning ownership, routing tasks through teams, and managing cross-functional collaboration. The goal is to build organizational thinking rather than memorize roles.

## ✨ Features Implemented

* 🏢 Multiple workplace environments (Tech Company, Startup, Corporate Office, Healthcare, Retail, and more)
* 🎯 Stage 1: **Who Owns This?** – Identify the primary owner for workplace tasks
* 🔄 Stage 2: **Task Routing** – Build the correct workflow across departments
* 🤝 Stage 3: **Collaboration Challenge** – Solve complex business scenarios with multiple teams
* 🎮 Drag-and-drop interactions with smooth animations
* 📊 Organizational Thinking Dashboard with visual insights
* 📈 Progress tracking across all stages
* 🌙 Premium dark glassmorphism UI
* 📱 Fully responsive design
* 💾 Completely offline with a single self-contained HTML file
