# 🚀 Day 40/60 – AI Assistant Builder | ABTalks 60 Days Claude AI Challenge



# 📖 Project Overview

**AI Assistant Builder** is a premium web application that helps users design and generate production-ready AI assistants through an interactive guided workflow. Instead of building a simple chatbot, the application creates complete AI assistant architecture—including system prompts, domain-specific interfaces, and implementation documentation.

---

# ✨ Features

## 🎯 Interactive Assistant Design

* Guided MCQ-based onboarding flow
* Assistant domain and niche selection
* Target audience identification
* User outcome definition
* Input method selection
* Output format configuration
* Tone and personality customization

## 🧠 Production-Ready System Prompt Generator

* AI role definition
* Scope and responsibilities
* Operational constraints
* Output formatting rules
* Edge-case handling
* Missing information strategy
* Safety and abuse protection
* Professional prompt structure

## 🎨 Smart Assistant Interface

* Purpose-built UI based on assistant type
* Responsive layout
* Smooth animations
* Loading & error states
* Empty state handling
* Claude API integration
* Modern user experience

## 📚 Documentation Panel

* Prompt architecture explanation
* UI design decisions
* Assistant workflow breakdown
* Future extension ideas
* Memory & tool integration concepts
* Multi-step workflow guidance

# 🚀 How to Run

1. Clone this repository.
2. Open the HTML file in your browser.
3. Complete the guided assistant-building questionnaire.
4. Generate the AI assistant.
5. Review the generated system prompt.
6. Explore the documentation panel.
7. Test different assistant configurations.

> **Note:** When running inside Claude.ai (Artifact mode), API requests are handled automatically. If hosting the HTML independently, you'll need a valid Anthropic API key for live Claude API functionality.
